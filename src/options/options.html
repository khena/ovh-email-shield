Paramètres OVH Email Shield

Configurez vos accès API OVHcloud pour activer la génération automatique d'alias.

Identifiants API OVH

Paramètres de Redirection

Le domaine hébergé chez OVH sur lequel créer les alias.
Votre vraie boîte mail recevant les courriers transférés.
Variables : [site] pour le site web visité, [rand] pour 6 caractères aléatoires (ex : shield-[rand] si vous ne voulez pas inclure le site).

Guide : Créer vos clés API OVH

Pour autoriser l'extension à ajouter des redirections sans exposer votre mot de passe OVH principal :

  1. Rendez-vous sur le générateur de clés OVH :
    Ouvrir OVH createToken ↗
  2. Définissez un nom d'application (ex : OVH-Email-Shield).
  3. Ajoutez les droits REST minimaux suivants : 
    GET  /auth/*
GET  /email/domain/*
POST /email/domain/*
DELETE /email/domain/*
  4. Validez et copiez l'Application Key, l'Application Secret et la Consumer Key.
🔒 Sécurité : Vos clés sont stockées localement dans votre navigateur (storage.local) et ne transitent jamais par aucun serveur tiers.
